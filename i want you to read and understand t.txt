# 7. SECURITY STANDARDS (NON-NEGOTIABLE)

## 7.1 Multi-tenancy
Every new table/resource gets tests that workspace A cannot read/patch/delete workspace B’s rows (same 18-pattern spirit). Sub-accounts must not leak to siblings.

## 7.2 XSS
Escape CRM fields, emails, AI chat, AI website HTML, review text, form fields before render.
Sanitize AI HTML to a safe tag allowlist: div, section, article, header, footer, h1–h6, p, span, img, a, ul, ol, li, button, table/thead/tbody/tr/td/th, figure, figcaption, svg (tight), br, hr, strong, em.
Strip script, iframe (unless sandboxed custom-code feature), object, embed, event handlers, `javascript:`, `data:text/html`, `vbscript:`.
Custom JS from clients: sandboxed iframe only (`sandbox="allow-scripts"` without `allow-same-origin`).

## 7.3 SSRF
For analyze-site, scan-site, import URL, favicon, link preview, webhooks-to-user-URL:
- Allow only http/https
- Block localhost, 127.0.0.1, 0.0.0.0, ::1, 169.254.0.0/16 (incl. 169.254.169.254), 10/8, 172.16/12, 192.168/16, link-local, metadata hostnames
- Resolve DNS then re-check IP (DNS rebinding)
- Timeout 5–10s, max body ~2–5MB, no redirect-to-private
- Tests must attempt 127.0.0.1, 169.254.169.254, and a redirect chain

## 7.4 Auth
Logout must destroy server session and reject the old token (this was Tier 3 — treat as real work, not trivia).
Demo workspace isolated + purged by existing cron; rate-limit demo creation.
Login lockout per email remains.
Never return whether an email exists vs wrong password in a way that contradicts existing behavior unless asked.

## 7.5 Public site serve
`GET /sites/:slug` (or equivalent) serves ONLY published content.
No drafts, no workspace ids, no keys, no PII, no debug.
Slug charset: lowercase alphanumeric + hyphen; uniqueness at DB constraint; reject `../` `%2e%2e` null bytes.
Published HTML should not depend on NVIDIA being up.

## 7.6 Secrets
Keys encrypted at rest. Never in git, logs, SSE errors, or frontend payloads.
`.gitignore` must cover `.dev.vars`, `.env`, `wrangler.toml` secrets, key files.

## 7.7 Rate limits
Preserve 9 existing limiters. New public or AI routes get a limiter. Do not weaken.
