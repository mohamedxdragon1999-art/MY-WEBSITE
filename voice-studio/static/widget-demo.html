🎧 Voice Studio — Embeddable Widget

This page simulates a customer's website. The floating headphones button in the bottom-right corner is the Voice Studio widget — the exact same experience your visitors get. Click it, then type or press the mic and talk. It streams the reply and speaks each sentence as soon as it is ready, and you can interrupt it at any time (barge-in).

Drop-in embed snippet

Add this one line to any website, just before </body>. Change data-site per website and point data-api at your deployed server. 

<script
  src="https://your-host/widget.js"
  data-site="acme"
  data-api="https://your-host"
  defer></script>

Optional: add data-token="..." if the tenant is configured to require an API token.

How multi-tenant works

Each website is a tenant identified by data-site. The server loads that tenant's own greeting, brand color, default voice, system prompt, brain provider/key and rate limits from tenants.json. One server can power many websites at once, each isolated from the others.
