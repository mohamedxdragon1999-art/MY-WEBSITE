# Tiny core the one-click launcher installs so the website works INSTANTLY.
#
# These are pure-Python / universally-wheeled packages, so pip can always find a
# prebuilt wheel for your Python (3.9 - 3.13+) and never has to compile anything.

# doesn't fail with "no matching distribution" on newer Python versions.
#
# With just these, the site runs with:
#   * the browser's built-in voice (zero extra downloads), and
#   * the offline "brain" for replies.
# The launcher then best-effort adds edge-tts (online neural "Current voice") and
# httpx (free cloud AI brain + Magpie). If those fail, the site STILL starts.
# To unlock the fully-offline Kokoro/Piper voices, install requirements.txt.
